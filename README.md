# 🔥 LED Chaser Circuit using 555 Timer & CD4017 (PCB Design)

## 📌 Overview
This project demonstrates an LED chaser circuit where LEDs glow sequentially to create a running light effect. The design uses a 555 timer in astable mode to generate clock pulses and a CD4017 decade counter to drive multiple LEDs.

---

## ⚙️ Components Used
- NE555 Timer IC  
- CD4017 Decade Counter IC  
- Resistors (150Ω, 10kΩ)  
- Capacitors (10µF, 10nF)  
- LEDs (10–11 LEDs)  
- 9V Power Supply  
- PCB designed using Autodesk Eagle  

---

## 🧠 Working Principle
- The **555 timer** operates in astable mode and generates clock pulses  
- These pulses are fed into the **CD4017 counter IC**  
- CD4017 activates outputs sequentially (Q0 → Q9)  
- Each output drives an LED, producing a chasing light effect  

---

## 🖥️ Design Details
- Schematic designed using Autodesk Eagle  
- PCB layout manually routed  
- Through-hole components used  
- Design Rule Check (DRC) performed  
- Proper component placement and routing ensured
